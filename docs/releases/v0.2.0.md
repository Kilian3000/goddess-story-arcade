# Pick your pack

A little more ceremony before the rip.

Updated September 7: corrected mobile pointer capture, spaced the packs farther apart, added floating wrappers, reflections and spring settling, and tuned the peek-edge thickness. Redundant phone arrows and the large next-card button are hidden, and the booster drawer now fully covers the controls underneath. The existing 0.2.0 download includes these fixes.

## Booster carousel

Browse a looping ring of twelve boosters. Drag to spin, let go to coast into a slot, or tap a side pack to bring it forward. Pick the front pack to lift it out and open it. Changed your mind? Go back to the ring before tearing.

The selection is cosmetic. Every position uses the same set and pull rules; nothing is drawn or counted until the wrapper is opened.

![Booster carousel](https://raw.githubusercontent.com/Kilian3000/goddess-story-arcade/v0.2.0/docs/showcase/pack-carousel.png)

## Phone opening

- Slow drags peek in any direction, exposing the opposite card edges.
- Quick flicks in any direction advance to the next card, never backward.
- Tap a card for its details. No separate phone peek button.
- The fixed touch surface stays separate from the animated stack.

This release also includes the recent wrapper, reveal-animation, foil-lighting, and immediate-audio updates. Desktop keeps its existing navigation and peek controls.

## Run or update

Download the source archive below, or pull the repository. The card catalog and artwork are included—no API key or separate image server is needed.

```sh
npm ci
npm run dev
```

For Docker, rebuild with `docker compose up --build`. Existing branding and data-source configuration still work. Browser saves use the same keys.

Checks: lint, 35 logic/data/source tests, production build, two server-rendering tests, and a browser walkthrough at phone size. This is not a physical-iPhone certification.
